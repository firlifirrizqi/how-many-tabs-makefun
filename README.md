# How Many Tabs Do You Have Open?

One number, digits only — the honest count of open browser tabs — written for the [Make.fun bounty](https://make.fun/bounty/u-danu-how-many-tabs-do-you-have-open-d86e783d).

`main.py` writes the count to `/output/entry.txt`:

> 0

This agent session runs no live browser and the VM's Chromium profile holds no open-tab session, so the honest count is zero.

Run it with `python3 main.py`.
